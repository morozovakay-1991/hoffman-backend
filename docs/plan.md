# Решения по архитектуре

- **Refresh-эндпоинт для токена (Этап 2, Auth API).** В разделе 0 плана упоминалась возможность отдельного refresh-эндпоинта для токена. В реализованном Auth API (register/login/logout/me) он не реализован — используется долгоживущий Sanctum-токен, а разлогин выполняется через `logout` или на клиенте по ответу `401`.
